Tab Limiter

Enforce a maximum number of unpinned tabs per browser window. When the limit is reached, any newly opened unpinned tab is closed immediately.

Notes

  • Pinned tabs (and Zen Essentials) are always allowed and never count.
  • The limit is enforced per window.
  • Lowering the limit never closes tabs that are already open.
  • On browser startup there is a short grace period so session restore is not interrupted.
  • The toolbar popup lets you change the limit for quick access.
